# Site map

- `profile/README.md`: public organization profile, linking canonical public product, package and research pages. This is the existing organization README.
- `CONTRIBUTING.md`: default contribution guidance; individual repository licenses and rights remain authoritative.
- `.github/ISSUE_TEMPLATE/package_bug.yml`: public package defect form.
- `.github/ISSUE_TEMPLATE/documentation_research.yml`: public documentation/research correction form.
- `.github/ISSUE_TEMPLATE/config.yml`: customer-support route; existing repository templates override these defaults.
- `SITE_MAP.md`: this map. No package dependency, model implementation, blanket license, tracking or scheduler is introduced.
